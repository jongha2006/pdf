# StudySync v0.1
아이폰 우선 PDF 비교 학습 웹앱입니다.

## 실행
폴더에서 `python -m http.server 8000` 실행 후 컴퓨터에서 http://localhost:8000 접속.
아이폰에서는 같은 Wi-Fi에 연결하고 `http://컴퓨터의_로컬_IP:8000`으로 테스트할 수 있지만, PWA 설치와 서비스 워커는 HTTPS 배포가 필요합니다.

## 배포
GitHub Pages 또는 Netlify 등 HTTPS 정적 호스팅에 이 폴더의 파일을 올리고 아이폰 Safari로 접속합니다. 공유 > 홈 화면에 추가 > 웹 앱으로 열기를 선택합니다.

## 기능
PDF 2개를 학습 세트로 저장, 탭 전환, 페이지별 위치 기억, 확대축소, 좌우 스와이프, IndexedDB 저장. PDF.js는 최초 온라인 로딩 후 캐시 상태에 따라 오프라인 작동할 수 있습니다.

## 주의
클라우드 동기화 없음. 브라우저 데이터 삭제 시 PDF가 삭제될 수 있습니다. 중요한 원본 PDF는 별도 백업하세요. PDF.js 라이브러리 캐시가 준비되지 않으면 오프라인 사용이 불가능합니다.
